az network local-gateway create --resource-group MyResourceGroup --location eastus --gateway-ip-address 94.0.252.160 --name LNG-HQ-Network --local-address-prefixes 10.1.0.0/16

🔁 Заміни MyResourceGroup на свою реальну ресурсну групу, наприклад: sandbox-rg

📌 Важливо:

  • PowerShell не підтримує багаторядковий синтаксис з \ як Bash.

  • У PowerShell пиши всю команду в один рядок, або обгорни її у скрипт-блок {} чи backtick (`) для переносу, але це не рекомендовано для CLI.

🔎 Приклад для вашого випадку:

powershell
az network local-gateway create `
  --resource-group sandbox-rg `
  --location eastus `
  --gateway-ip-address 94.0.252.160 `
  --name LNG-HQ-Network `
  --local-address-prefixes 10.1.0.0/16

Тут використовуються зворотні апострофи (backticks `) — це дозволено в PowerShell для переносу рядка, якщо дуже треба.

Ваша команда не спрацювала через відсутність пробілу між аргументами --resource-group і MyResourceGroup, а також можливо інші дрібні синтаксичні помилки.

powershell
az network vnet subnet create --resource-group MyResourceGroup --vnet-name HQ-Network --name GatewaySubnet --address-prefixes 172.16.255.0/27

📌 Пояснення параметрів:

  • --name GatewaySubnet — ім’я сабнету (обов’язково саме GatewaySubnet для VPN)

  • --address-prefixes 172.16.255.0/27 — CIDR-діапазон для сабнету

🔁 Замініть MyResourceGroup на актуальну назву ресурсної групи, якщо вона інша (наприклад sandbox-rg).
